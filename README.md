## Lab Description
This lab introduces client-side JavaScript programming.
It covers functions, event handling, conditions, input
validation, loops and DOM manipulation.

## Question 1 - Interactive Text Changer
Changes the paragraph text when the user clicks the
Change Message button.

How to run:
1. Open the Q1 folder.
2. Open index.html in a browser.
3. Click Change Message.

## Question 2 - Smart Number Validator
Accepts a number and checks whether it is lower than,
higher than or equal to 10.

How to run:
1. Open the Q2 folder.
2. Open index.html in a browser.
3. Enter a number.
4. Click Check.

## Question 3 - Dynamic Number Generator
Generates an ordered list containing numbers from 1 to 5.

How to run:
1. Open the Q3 folder.
2. Open index.html in a browser.
3. Click Generate.
